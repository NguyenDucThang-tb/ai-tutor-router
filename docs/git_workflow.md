# Git workflow

The reviewed baseline is maintained on `main`. Start each implementation phase from the latest `main` and use the phase branch specified in the project task plan (for example, `feat/phase1-completion` or `feat/phase2-dataset-benchmark`). Commit coherent changes, push the feature branch, and open a pull request targeting `main` with test evidence and limitations. Review before merging; do not merge automatically.

The initial repository commit records the Phase 0 / partial Phase 1 baseline. It does not claim a verified API integration or completed test suite.
